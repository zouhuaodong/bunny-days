# 小兔日和 · 东

一个为「东」做的照片互动小网站：摸摸、喂胡萝卜、玩毛球、哄睡，还会记住亲密度。

## 在线打开

https://zouhuaodong.github.io/bunny-days/

手机微信直接打开即可，建议收藏或添加到桌面。

![小兔日和二维码](qr-github.png)

## 怎么玩

- **摸摸**：手指在小兔身上滑动，会冒爱心、呼噜呼噜，亲密度上涨
- **喂胡萝卜**：胡萝卜会飞到嘴边，咔嚓咔嚓吃掉，饱腹度上涨
- **玩毛球**：毛球弹跳，小兔跟着蹦，心情上涨
- **哄睡**：进入夜晚模式，小兔戴上眼罩，精力恢复；点「轻轻叫醒它」醒来
- **小兔手账**：查看亲密度、饱腹、心情、精力、成就，也可以改名
- **明信片**：手账底部生成带真实照片的明信片，长按保存

## 文件

- `index.html`：网页本体
- `bunny.png`：透明背景的小兔照片抠图
- `bunny_photo.jpg`：手账里的真实照片

名字默认是「东」，状态保存在浏览器 `localStorage` 里。

## 本地预览

在这个目录启动一个静态服务器，例如：

```bash
python -m http.server 4173
```

然后打开 http://127.0.0.1:4173/
