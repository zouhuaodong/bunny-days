# 东的小兔屋

一个横屏的兔子互动养成小游戏：和东住在同一间小屋里，抚摸、喂食、玩耍、换装、睡觉，还可以签到、做任务、玩小游戏、冒险和战斗。

## 在线打开

https://zouhuaodong.github.io/bunny-days/

手机微信直接打开，**把手机横过来玩**。建议添加到桌面。

![小兔屋二维码](qr-github.png)

## 玩法

- **抚摸**：手指在东身上滑动，会冒爱心、呼噜呼噜，提升亲密度和心情
- **喂食**：胡萝卜、苹果、小饼干，补充饱腹度，也会影响心情
- **玩耍**：追毛球小游戏，得分换金币，提升心情
- **换装**：小花、围巾、小皇冠、蝴蝶结、墨镜、星星，可以一直穿着
- **睡觉**：进入夜晚模式，恢复精力
- **签到 / 奖励**：每日签到、每日任务，领金币和宝石
- **小游戏**：接胡萝卜，20 秒得分换金币
- **冒险**：胡萝卜田、蘑菇林、星光湖，带回金币、食物或宝石
- **战斗**：帮东赶走灰尘怪，胜利有金币和宝石
- **恢复**：东累了的时候，让它休息一下

## 说明

- 这是纯静态网页，不需要服务器逻辑；所有状态保存在浏览器 `localStorage`
- 音效需要先点一下页面才会开启
- 横屏体验最佳；竖屏会提示旋转手机
- `bunny.png` 是东的透明背景照片抠图，`bunny_photo.jpg` 是头像和照片

## 文件

- `index.html`：游戏页面
- `styles.css`：房间、UI、动画
- `game.js`：状态、互动、小游戏
- `bunny.png` / `bunny_photo.jpg`：东的照片素材
- `qr-github.png`：在线地址二维码
