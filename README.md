# 东的小兔屋

一个竖屏的兔子互动养成小游戏：和东住在同一间小屋里，抚摸、喂食、玩耍、换装、睡觉、亲昵，还可以签到、做任务、玩小游戏、冒险、战斗和跑酷。东会叫玩家“鸦鸦主人”。

## 在线打开

https://zouhuaodong.github.io/bunny-days/

手机微信直接打开，**竖屏玩**。建议添加到桌面。

![小兔屋二维码](qr-github.png)

## 玩法

- **抚摸**：手指在东身上滑动，会冒爱心、呼噜呼噜，提升亲密度和心情
- **喂食**：胡萝卜、苹果、小饼干，补充饱腹度，也会影响心情
- **玩耍**：追毛球小游戏，得分换金币，提升心情
- **换装**：小花、围巾、小皇冠、蝴蝶结、墨镜、星星，可以一直穿着
- **亲昵**：抱抱、亲亲、贴贴、举高高；双击东亲亲，长按东抱抱，会脸红、冒爱心
- **睡觉**：进入夜晚模式，恢复精力
- **签到 / 奖励**：每日签到、每日任务，领金币和宝石
- **小游戏**：接胡萝卜，20 秒得分换金币
- **冒险**：胡萝卜田、蘑菇林、星光湖，带回金币、食物或宝石
- **战斗**：帮东赶走灰尘怪，胜利有金币和宝石
- **跑酷**：三条车道，左右换道、跳跃、滑铲，躲开卡车和路障；收集金币和胡萝卜，带奖励回小屋
- **恢复**：东累了的时候，让它休息一下

## 说明

- 这是纯静态网页，不需要服务器逻辑；所有状态保存在浏览器 `localStorage`
- 音效需要先点一下页面才会开启
- 竖屏体验最佳；横屏会提示旋转手机
- 东的所有回答都会带上“鸦鸦主人”；亲昵互动会增加心情、经验和每日任务进度
- 跑酷玩法参考开源 Unity 项目 [Game_Parkour](https://github.com/764424567/Game_Parkour) 的三车道、跳跃 / 滑铲、障碍随机和道路循环设计，用 Canvas 重写成适合微信打开的竖屏版本
- `bunny.png` 是东的透明背景照片抠图，`bunny_photo.jpg` 是头像和照片

## 文件

- `index.html`：游戏页面
- `styles.css`：房间、UI、动画
- `portrait.css`：竖屏布局
- `parkour.css`：跑酷界面
- `game.js`：状态、互动、小游戏和跑酷
- `bunny.png` / `bunny_photo.jpg`：东的照片素材
- `qr-github.png`：在线地址二维码
